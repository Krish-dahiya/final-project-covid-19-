# Short Project Presentation (Simple Hinglish)

**Good morning everyone.**

Mere project ka naam **COVID-19 Data Analysis and Visualization** hai.

Is project ka main objective historical COVID-19 data ko analyze karna aur graphs ki help se samajhna hai ki time ke saath reported cases aur deaths kaise change hue.

Maine Python language use ki hai. Data ko read aur analyze karne ke liye Pandas, aur graphs banane ke liye Matplotlib aur Seaborn libraries use ki hain.

Program historical CSV files download karta hai. Phir data ko load karke global trends, top 10 countries ke confirmed cases, top 10 countries ke reported deaths, aur ek correlation heatmap banata hai.

Graphs `graphs` folder mein save ho jaate hain. In graphs se data ko table ke comparison mein samajhna easy hota hai.

Is project ki limitation yeh hai ki yeh reported historical data par based hai. Har country ka reporting method alag ho sakta hai, aur recovery data kuch later dates ke liye incomplete ho sakta hai.

**Thank you.**
