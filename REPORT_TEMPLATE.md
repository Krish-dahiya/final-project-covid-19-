# COVID-19 Data Analysis and Visualization — Project Report

## 1. Introduction
COVID-19 spread across many countries and affected public health and everyday life. This project uses historical reported data and visualizations to explore changes over time.

## 2. Objective

- Visualize global trends over time.
- Compare reported totals across countries.
- Explore relationships between country-level totals.
